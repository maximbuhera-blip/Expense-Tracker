# Рахуй — трекер особистих витрат

Навчальний вебзастосунок на HTML, CSS і JavaScript без React, сервера чи бази даних.

## Як запустити

Відкрийте `index.html` у браузері. За бажанням завантажте файли в репозиторій GitHub Pages, щоб опублікувати статичний сайт.

## Можливості

- Додавання витрат із назвою, сумою та категорією: Їжа, Транспорт, Покупки або Інше.
- Перевірка, що назва заповнена, а сума більша за нуль.
- Список витрат із можливістю видалити окремий запис.
- Загальна сума, кількість записів, середня витрата та суми за категоріями.
- Фільтр категорій, пошук за назвою в реальному часі й очищення списку з підтвердженням.
- Збереження витрат у LocalStorage браузера.
- Навчальна форма реєстрації з JavaScript-валідацією і повідомленням про успіх. Пароль не зберігається.
- Адаптивне оформлення для комп’ютерів і телефонів.

## Файли

- `index.html` — розмітка застосунку.
- `styles.css` — оформлення та адаптивність.
- `app.js` — логіка, валідація й LocalStorage.
